📋 סיכום הקוד

זרימת העבודה:

  1. משתמש לוחץ "New Note": חלון עריכה מופיע (editor)
  2. משתמש כותב כותרת + תוכן: טקסט הכלול בשדות
  3. משתמש לוחץ "Save": פתק חדש נוסף לרשימה פנימית (array)
  4. renderNotes() נקראת: כל הפתקים מחדש מחוסלים ומכוללים
  5. פתקים מופיעים בסיידבר: כשמרחפים - כפתורי עריכה/מחק מופיעים
  6. משתמש לוחץ ערוך: הפתק טעון לעורך לעדכון
  7. משתמש לוחץ מחק: פתק הוסר מהרשימה ו-renderNotes() מתעדכן
